# Ứng dụng Tính Lương Nghỉ Hưu

Ứng dụng web giúp tính toán chế độ và lương hưu cho cán bộ, giáo viên. Được xây dựng bằng Next.js và Tailwind CSS.

## Tính năng
- Tính toán tuổi nghỉ hưu chuẩn theo NĐ 135/2020.
- Tính toán lương hiện tại và dự kiến mức lương hưu.
- Hỗ trợ các điều kiện nghỉ hưu sớm.
- Giao diện trực quan, dễ sử dụng.

## Bắt đầu

Cài đặt các gói phụ thuộc:
```bash
npm install
```

Chạy môi trường phát triển:
```bash
npm run dev
```

Mở trình duyệt tại [http://localhost:3000](http://localhost:3000).

## Công nghệ sử dụng
- Next.js (App Router)
- React
- Tailwind CSS
- shadcn/ui
